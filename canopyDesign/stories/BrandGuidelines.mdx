## Spacing Scale

| Token | Value | Usage |
|---|---|---|
| `--bcone-spacing-1` | 4px | Tight gaps, icon padding |
| `--bcone-spacing-2` | 8px | Component internal padding |
| `--bcone-spacing-4` | 16px | Default content padding |
| `--bcone-spacing-6` | 24px | Card padding, section gaps |
| `--bcone-spacing-8` | 32px | Between sections |
| `--bcone-spacing-12` | 48px | Page section breaks |
| `--bcone-spacing-16` | 64px | Hero / major section separation |

## Border Radius

| Token | Value | Usage |
|---|---|---|
| `--bcone-radius-sm` | 4px | Inputs, buttons, cells |
| `--bcone-radius-md` | 8px | Cards, dropdowns, modals |
| `--bcone-radius-lg` | 12px | Large panels |
| `--bcone-radius-pill` | 9999px | Tags/badges only |

---

## Design Principles

1. **Clean, confident, corporate** — SAP Fiori meets modern SaaS
2. **Generous whitespace** — use the spacing scale, not ad-hoc values
3. **Sharp geometry** — 4px radius for controls, 8px for cards; no pill shapes except badges
4. **Subtle elevation** — `box-shadow` conveys depth, not color fills
5. **Token-first** — never hardcode a hex color; always use `var(--bcone-*)` or Tailwind `bcone-*` classes
